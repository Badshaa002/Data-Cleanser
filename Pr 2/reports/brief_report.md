
Brief Report

1. Most Effective Imputation Strategy:
MICE was the most effective imputation method because it uses relationships between multiple variables to estimate missing values more accurately.

2. Best Outlier Handling Method:
Winsorization preserved data quality best because it reduced the effect of extreme values without removing patient records from the dataset.

3. Improvement in Dataset Usability:
Data cleaning improved the dataset by removing missing values, controlling outliers, and making the dataset more suitable for machine learning tasks such as disease risk prediction.
